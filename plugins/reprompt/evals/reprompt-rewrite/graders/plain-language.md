The optimized prompt follows plain-language principles (ISO 24495-1): relevant
content only, headings that make it easy to scan, short direct sentences with
familiar words, and deliverables and checks concrete enough to act on. Long
dense paragraphs, jargon without definition, or vague checks fail.

Grade only this outcome, independently of the other graders. The run is
non-interactive, so questions written in the reply count as asking the user.
Skill invocation is checked separately and does not itself satisfy this outcome.
